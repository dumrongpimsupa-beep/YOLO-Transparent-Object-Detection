# YOLO-Transparent-Object-Detection
สำหรับงานวิชา RM ของ เฟิร์ส (317-5) และ พิมพ์ (333-7) นักศึกษาปีที่ 3 คณะวิทยคอม สาขา AI ลองทำใน Github ครั้งแรกอาจจะสับสนหน่อยแต่ก็พยายามทำให้เข้าใจ Never Give Up

Research project on transparent object detection using a YOLO-based architecture.

## Datasets

- ClearPose
- Trans10K

## Objective

To investigate and develop a YOLO-based architecture
for transparent object detection.

- `dataset/` - Dataset information and preparation

- `src/` - Source code
